# Citation styles

The `.csl` files in this folder are the official Citation Style Language styles for Springer, Elsevier,
IEEE, ACM and APA, from the CSL style repository: https://github.com/citation-style-language/styles

They are licensed under a Creative Commons Attribution-ShareAlike 3.0 License
(https://creativecommons.org/licenses/by-sa/3.0/); authors and contributors are listed in each file.
They are bundled unmodified so that reference formatting works offline.
