# Showcase samples

A fictional case study, **InvoiceFlow**, with everything needed to try every feature of Zensar Content Studio.
All names and numbers are made up; nothing here is Zensar or customer data.

| File | Use it for |
|---|---|
| `InvoiceFlow_Showcase.docx` | The main document. It has an executive summary, the problem, an architecture section with an embedded diagram, a workflow, a tech stack, a timeline, a results table and a monthly-volume table (these become KPIs and a chart), a before/after comparison, a client quote, risks, recommendations and a conclusion. |
| `demo_invoiceflow.mp4` | A 25-second product demo (login → dashboard → upload → results → settings). It is analysed frame by frame and narrated scene by scene. |
| `narration_script.md` | An optional script with `## Slide N` markers. Paste or import it as the narration script. |
| `background_music.mp3` | A 30-second music bed, generated by `make_showcase.py`. It loops to the video length, fades in and out, and dips under narration. |
| `brand_backdrop.png` | An extra still for the video timeline. Use it to try Ken Burns zoom, crop and duration. |
| `architecture_diagram.png` | The document's Figure 1. It can also be added to the video. |

Regenerate the files at any time with `python samples/make_showcase.py`.

## One command

With the app running (`start.bat`):

```bat
python samples\run_showcase.py            :: document + demo video
python samples\run_showcase.py --github   :: + this repository from GitHub (downloaded once)
```

It uploads the sources and creates a 10-slide project in the **Zensar Experience** template, with narration, script, music and an extra image. It then generates the deck, visuals, PDF and video. Finally it trims, speeds up and crops the demo clip on the timeline and renders a quick preview. Open the link it prints.

## Step by step in the app

1. **New project → Sources.**
   - Drop `InvoiceFlow_Showcase.docx` and `demo_invoiceflow.mp4` together.
   - Optionally import `https://github.com/V-JasonEmmanuel/Zen-TMT` under *Import a GitHub repository*. This explains the code itself: architecture diagram, workflow, tech stack and API.
2. **Brand & template.** Keep **Zensar Experience**, the LinkedIn design language, or compare the other presets using their previews.
3. **Instructions.** Try: *"Create a 10-slide client presentation about InvoiceFlow: overview, the problem, architecture, workflow, results with the key metrics, before and after, and recommendations."*
4. **Outputs & video.**
   - Tick Video.
   - Narration: *Offline voice*, and import `narration_script.md`. Or choose *My own recording* and upload a voice memo.
   - Music: upload `background_music.mp3`.
   - Images & videos: add `brand_backdrop.png`.
5. **Generate.** Then review:
   - **Presentation.** Architecture diagram, workflow, KPI panel and chart from the tables, the client quote on a lavender slide, and takeaways.
   - **Images.** Every visual as PNG, JPG or SVG.
   - **Sources.** Every statement is linked to its page and section, or to the video scene.
6. **Video editor.**
   - Click the demo clip. Drag the trim sliders or use *Set start/end at playhead*, pick 1.25×, and press **Crop** to drag the box.
   - The preview loops exactly what will be rendered.
   - Drag the backdrop clip to a new position, attach your own recording to a slide, adjust the music volume and ducking, then **Render preview** or **Render final video**.
